d) foldr y foldl dan resultados distintos porque asocian la aplicacion
del operador binario en sentidos opuestos: foldr asocia por la derecha,
agrupando los términos de la forma 1 - (2 - (7 - (8 - 0))),
mientras que foldl asocia por la izquierda, agrupando la operación 
como (((0 - 1) - 2) - 7) - 8. Como la resta no es ni asociativa ni
conmutativa, cambiar el orden de agrupación altera la evaluacion.
Para que foldr op z xs == foldl op z xs se cumpla para cualquier lista 
finita xs, se requiere que el operador op sea asociativo 
($a \text{ op } (b \text{ op } c) = (a \text{ op } b) \text{ op } c$), 
conmutativo ($a \text{ op } b = b \text{ op } a$), y que el valor z 
sea el elemento neutro del operador ($a \text{ op } z = a$). 
Es decir, que el tipo de los elementos junto con op y z formen 
un monoide conmutativo.
